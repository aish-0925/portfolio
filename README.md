# Aishwarya A Poojary — Portfolio

A personal developer portfolio showcasing my background, technical skills, internship experience, projects, education, and certifications.

The website is designed with a clean, scrapbook-inspired visual style, a warm cream background, sage-green accents, and responsive layouts for desktop and mobile screens.

## Features

- **Introduction:** A brief overview and links to my professional profiles.
- **About:** My interests, background, and development focus.
- **Skills:** Technical skills organized by category.
- **Experience:** My .NET Developer internship experience at Manipal Technologies Limited.
- **Projects:** Selected work in full-stack development, AI/ML, and NLP.
- **Education:** Academic background.
- **Certifications:** Courses and certifications.
- **Responsive navigation:** Mobile-friendly navigation and layouts.
- **Project showcase:** Project cards with screenshots and technology details.
- **Resume:** A link to view or download my resume.

## Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Build Tool:** Vite
- **Additional Libraries:** Lenis, Swiper, React Simple Typewriter

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/aish-0925/portfolio.git
   ```

2. Move into the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal (usually `http://localhost:5173`).

## Available Scripts

| Command | Description |
